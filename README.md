# SnakesWin

**SnakesWin** is a multiplayer Snake & Ladder betting game built on the Solana blockchain.

Players join a game room, place their SOL bets, and compete in real time.  
The winner receives nearly 2× the pooled bet amount, while the platform takes a small fee from the profit.

---

## ✨ Features

- 🧑‍🤝‍🧑 Multiplayer game rooms  
- 💸 SOL-based betting  
- 🏆 Automatic winner payout  
- 🔎 Transparent blockchain transactions
